## 基本目錄
### 1. 系統核心與開機相關

- **`/boot`**：存放開機引導程式（如 GRUB）與系統核心（Kernel）檔案。
- **`/proc`**：虛擬檔案系統，存在於記憶體中，包含當前系統核心、行程（Processes）與硬體狀態的即時資訊。
- **`/sys`**：虛擬檔案系統，類似 `/proc`，但更結構化地展示硬體裝置與核心模組的資訊。

### 2. 系統設定與管理 (運維重點)

- **`/etc`**：**全域系統設定檔**的集中地。各種服務（如網路設定、SSH、Web Server 等）的配置檔都在這裡。通常不包含執行檔。
- **`/var`**：存放**經常變動的資料 (Variable data)**。對於運維極為重要，包含系統日誌檔 (`/var/log`)、資料庫檔案、郵件儲存列隊等。
- **`/run`**：存放系統自上次開機以來的暫存資訊（如服務的 PID 檔、Socket 檔），重新開機後會清空。

### 3. 使用者與應用程式資料

- **`/home`**：一般使用者的家目錄，存放個人檔案與使用者層級的設定。
- **`/root`**：系統管理員（root 帳號）的專屬家目錄。
- **`/usr`**：**User System Resources**。包含系統核心之外的大多數應用程式、函式庫、說明文件等。這是系統中佔用空間最大的目錄之一。
- **`/opt`**：**Optional**。通常用於安裝非透過系統套件管理員（如 APT）安裝的第三方大型軟體或獨立套件。
- **`/srv`**：**Services**。存放系統提供的特定服務所需的資料，例如網頁伺服器的網站資料可能會自定義存放在此。

### 4. 裝置、掛載點與暫存

- **`/dev`**：存放裝置檔案（Device files）。Linux 中「一切皆檔案」，這裡將硬體（如硬碟、終端機）映射為可存取的檔案。
- **`/mnt`**：**Mount**。通常提供給系統管理員**手動**掛載其他檔案系統或硬碟區塊的目錄。
- **`/media`**：系統**自動**掛載的抽取式媒體（如 USB 隨身碟、光碟）的預設位置。
- **`/tmp`**：提供給系統或應用程式存放暫存檔的地方。通常在系統重新開機時會被清空。

### 5. 特殊目錄與檔案

- **`/snap`**：Ubuntu 特有的 Snap 套件管理器使用的掛載目錄。
- **`/cdrom`**：歷史遺留的目錄，通常作為光碟機的掛載點。
- **`/lost+found`**：當檔案系統發生異常（如不正常斷電），透過 `fsck` 工具修復後，找回的孤立檔案碎片會存放在此。
- **`swap.img`**：**置換空間檔案**。當伺服器的實體記憶體 (RAM) 不足時，系統會將這個檔案當作虛擬記憶體來使用。

### 重要架構概念：usr-merge 

圖片最下方可以看到 `bin@ --> usr/bin`、`sbin@ --> usr/sbin` 等綠色字體，以及 `bin.usr-is-merged/` 這樣的目錄。

- **傳統架構**：過去的 Linux 會將基本且開機必要的指令放在根目錄的 `/bin` 與 `/sbin`，而將非必要的放在 `/usr/bin` 與 `/usr/sbin`。
- **現代 Ubuntu 架構 (usr-merge)**：為了簡化系統設計與套件管理，現代發行版已經將根目錄下的執行檔與函式庫目錄**全部整併進 `/usr` 目錄底下**。
- 您看到的 `bin@` 是一個**符號連結 (Symlink)**，它告訴系統：「當有人尋找 `/bin` 時，請直接導向 `/usr/bin`」。`sbin` (系統管理指令)、`lib` (函式庫) 同理。

## 檔案操作指令

#### `cd` (Change Directory) - 切換工作目錄

- `cd /home/tony`：切換到絕對路徑。
- `cd ..`：回到上一層目錄（兩個點代表父目錄）。
- `cd ~` 或單獨輸入 `cd`：直接回到當前使用者的家目錄（`/home/使用者` 或 `/root`）。
- `cd -`：切換回「上一次」所在的目錄。常在兩個長路徑之間來回切換時使用。

#### `ls` (List) - 列出目錄內容

- **`-l` (Long format)**：顯示詳細資訊，包含權限、擁有者、群組、大小、修改時間。
- **`-a` (All)**：顯示所有檔案，包含以 `.` 開頭的隱藏檔（例如 `.env` 或 `.bashrc`）。
- **`-h` (Human-readable)**：與 `-l` 搭配，將檔案大小轉換為 KB, MB, GB 格式，而不是預設的 Byte。
- **`-t` (Time)**：依照修改時間排序，最新的在最上面。

##### 特殊:
 - `ls -lah`：詳細列出所有包含隱藏檔的大小與權限，且容易閱讀。
 - Ubuntu 預設提供了一個捷徑指令 **`ll`**，它等同於 `ls -alF`。


#### `mkdir` (Make Directory) - 新增資料夾

- `mkdir new_folder`：在當前目錄建立名為 `new_folder` 的資料夾。
- **`-p` (Parents)**： 遞迴建立目錄。例如 `mkdir -p /opt/project/app/src`，如果前面的目錄不存在，系統會自動幫您一併建立，不會報錯。

#### `touch` - 新增空檔案 / 更新時間戳記

- `touch config.json`：如果檔案不存在，會建立一個內容為空的 `config.json` 檔。如果檔案已存在，則會把檔案的「最後修改時間」更新為現在（不改變內容）。

#### `cp` (Copy) - 複製檔案或資料夾

- `cp file1.txt file2.txt`：將 `file1.txt` 複製一份命名為 `file2.txt`。
- **`-r` (Recursive)**：複製資料夾必備。`cp -r /opt/minecraft /backup/minecraft_bak` 會將整個資料夾包含其內容完整複製過去。
- **`-p` (Preserve)**：複製時保留檔案的原始屬性（如擁有者、群組、權限、時間戳記）。例如備份設定檔時常使用 `cp -p config.yml config.yml.bak`，避免權限跑掉導致服務啟動失敗。

#### `mv` (Move) - 移動或重新命名;  兩種功能，取決於您的目標路徑。

- **移動**：`mv app.js /opt/project/` 將當前目錄的 `app.js` 移動到指定資料夾內。
- **重新命名**：`mv old_name.txt new_name.txt` 在同一個目錄下，這就是重新命名。
- **覆蓋前警告 (`-i`)**：`mv -i source target` 如果目標位置已經有同名檔案，會先詢問您是否要覆蓋（Interactive），防呆專用。

#### `rm` (Remove) - 刪除檔案與目錄
- **刪除單一檔案**：`rm index.html`刪除當前目錄下的 `index.html`
- **刪除前警告 (`-i`)**：`rm -i important.conf` 在刪除每一個檔案前，系統都會暫停並詢問您 `rm: remove regular file '...'?`，您必須輸入 `y` 才會真正刪除。這是防止手滑誤刪的好習慣。
- **遞迴刪除 (``-r`` 或 ``-R``)**：**如果要刪除的是「資料夾」，就必須加上這個參數。** 否則系統會報錯 `rm: cannot remove '...': Is a directory`。它會深入該目錄，將裡面的檔案與子目錄一層層全部刪除。EX：`rm -r /opt/old_project/`
- **強制刪除 (``-f``)**：忽略不存在的檔案，並且**絕對不會跳出任何確認提示**。EX：`rm -f /var/log/temp_error.log`
#### `rmdir` (Remove Directory) - 刪除空目錄(保守)
- **語法：** `rmdir empty_folder/`
- **特性：** **只能**刪除裡面完全沒有任何檔案、也沒有隱藏檔的「空資料夾」。只要裡面有一丁點東西，它就會報錯並拒絕執行。在實務上，這是一種確保不會意外刪除重要資料的安全機制。

## 檔案權限

#### 「檔案」(File) 時

- **r (讀取)**：您可以使用 `cat` 指令查看檔案的內容。
- **w (寫入)**：您可以使用 `nano` 或 `vim` 編輯裡面的文字，甚至清空它。
- **x (執行)**： 當這是一個腳本（ `.sh` ）且擁有 `x` 權限時，系統才允許您將它當作程式來啟動（例如輸入 `./script.sh`）。沒有 `x`，它就只是一堆純文字。

#### 「資料夾」(Directory) 

這稍微反直覺，請把資料夾當作「一個有門鎖的房間」。

- **r (讀取)**：您可以看見房間裡「有哪些東西」。允許您使用 `ls` 指令列出裡面的檔案名稱。
- **w (寫入)**：您可以改變房間的「內部佈置」。允許您在這個資料夾裡面**新增 (`touch`)、刪除 (`rm`) 或重新命名 (`mv`) 檔案**。（注意：就算檔案本身的權限是唯讀，只要您對它所在的「資料夾」有 `w` 權限，您照樣可以把它強制刪除！）
- **x (執行)**： 類比「進入權」。沒有 `x` 權限，您就無法使用 `cd` 指令進入該資料夾，也無法讀取裡面任何檔案的內容，就算有 `r` 權限也沒用。

#### 檔案類型 + UGO 權限分配表
- **第 1 碼 `[-]` (類型)**：
    - `-` 代表這是一個普通檔案 (File)。
    - `d` 代表這是一個目錄/資料夾 (Directory)。
- **第 2~4 碼 `[rwx]` (擁有者權限)**： 代表檔案擁有者可以讀、寫、執行。
- **第 5~7 碼 `[r-x]` (群組權限)**： 代表群組成員可以讀、可以執行，但**不能修改 (`-` 代表該位置沒有權限)**。
- **第 8~10 碼 `[r--]` (其他人權限)**： 代表路人只能讀取，不能修改也不能執行。

## 使用者與群組

### 查看使用者
#### `whoami` (Who am I) - 輸出當前使用者名稱
- `whoami`：輸出當前使用者名稱 EX：`tony`

#### `id` 輸出當前使用者資料
- `id`：輸出當前使用者資料，EX：`uid=1000(tony) gid=1000(tony) groups=1000(tony),4(adm),24(cdrom),27(sudo),30(dip),46(plugdev),101(lxd)`
- `id -u/-g/-G`：輸出使用者ID(UID)、主要群組ID(GID)、所有群組ID
- `id -un/-gn/-Gn`：輸出成**名稱**
- `id <username>`：查看使用者資料
- `id --help`：查看全部指令

### 使用者 建、刪、改 (需要sudo)
#### `useradd` 新增使用者
- `useradd <username>`：新增使用者
- **`-m`**：強制**建立家目錄**(預設路徑為 `/home/username`)
- **`-s`**：指定預設的 **Shell**(Ubuntu預設常是`/bin/sh`，強烈建議指定為更人性化的`/bin/bash`)，P.S 終端:正常`/bin/bash`、古老`/bin/sh`、防人`/usr/sbin/nologin`；`/etc/shells`看
- **`-g`**：指定**主要群組**(可以是群組名或 GID)
- **`-G`**：指定**次要群組**(多個群組用逗號隔開)
- **`-c`**：加入**註解/說明**(例如使用者的真實姓名或部門)
- EX：建立一個叫 `kyle` 的使用者，自動建家目錄、指定 bash、加入 `sudo` 特權群組，並加上部門註解。建立完後尚未有**密碼**，需要`sudo passwd kyle`新增密碼。
```Bash
sudo useradd -m -s /bin/bash -G sudo -c "IT Dept - Kyle" kyle
```

#### `userdel` 刪除群組
- `userdel <username>`：刪除使用者，EX：`sudo userdel kyle`，帳號消失了，但 `/home/kyle` 還在，檔案的所有者會變成該帳號原本的 UID 數字。
- `-r`：徹底刪除(通常確保資料備份完成後用)，只有`/home/kyle`、`/var/spool/mail/kyle`的當案會刪除，EX：`sudo userdel -r kyle`
- 刪除標準流程
```Bash
sudo killall -u kyle
sudo userdel -r kyle
# 搜查全系統中，原本屬於 kyle 但沒被刪乾淨的漏網檔案
sudo find / -uid 1001
#=====或=====
# 找出所有 UID 屬於 1001 的檔案並刪除
sudo find / -uid 1001 -delete
# 或者：找出所有失去擁有者 (無效 UID) 的檔案並刪除
sudo find / -nouser -delete
#=====或=====
# 1. 找出所有屬於 1001 的檔案，將擁有者改為 boss
sudo find / -uid 1001 -exec chown boss {} +
# 2. 或者更安全的做法，直接針對無主檔案進行移交
sudo find / -nouser -exec chown boss {} +
```
 

#### `usermod` (User Modify) 修改使用者
- **`-c`**：修改使用者註解
- **`-s`**：修改預設 Shell(例如將某人關閉登入權限，改為 `/usr/sbin/nologin`)
- **`-l`**：**修改帳號名稱**(變更登入名字)
- `-L`：鎖定帳號(不可登入)
- `-U`：解鎖帳號
- **`-d` -m**：變更家目錄路徑。`-d` 指定新路徑，**務必搭配 `-m`** 才會把舊家目錄的檔案自動搬過去。
- **`-aG`**：**追加次要群組**。這兩個字母通常一起出現(Append + Group)，**千萬不能漏掉 `-a`**，否則該使用者原本的其他次要群組會全部被洗掉！
- 範例
```Bash
#將 kyle 的登入名稱改為 kyle.lin
sudo usermod -l kyle.lin kyle
#將使用者加入 `docker` 群組（不影響舊群組）
sudo usermod -aG docker kyle.lin
```







### 查看群組

#### `groups` 輸出使用者群組
- `groups`：輸出當前使用者群組，EX：`tony adm cdrom sudo dip plugdev lxd`
- `groups <username>`：輸出使用者群組

#### `getent group` (Get entries) - 特定群組有什麼使用者
- `getent group <groupname>`：輸出範例EX(sudo)：`sudo:x:27:tony`

### 群組 建、刪、改 (需要sudo)
#### `groupadd` 建立群組
- `groupadd <groupname>`：建立群組，EX：`sudo groupadd devops`

#### `groupdel` 刪除群組
- `groupdel <groupname>`：刪除群組，EX：`sudo groupdel devops`

#### `groupmod` 修改群組
- `groupadd -n <old_groupname> <new_groupname>`：修改名稱，EX：`sudo groupmod -n new-devops old-devops`
- `groupadd -g <new_groupid> <groupname>`：修改GID(通常避免使用)，只會更改`/etc/group`裡面的數字，不會自動更改檔案所屬GID。通常搭配`find`、`chown`處理就有檔案權限。
```
# 將 "sre" 群組的 GID 修改為 2001 
sudo groupmod -g 2001 sre
# 1. 找出全系統中屬於舊 GID (1005)的檔案，並將其改為新群組 "sre"
sudo find / -gid 1005 -exec chgrp sre {} +
# 2. 或者直接用數字對數字更新
sudo find / -gid 1005 -exec chgrp 2001 {} +
```
- `-o`：配合`-g`允許重複GID

## ch系列指令 (需要sudo)

#### `chmod` (Change Mode) — 變更檔案/目錄的「存取權限」
- **語法邏輯：** 區分為三大對象：`u` (User/擁有者)、`g` (Group/群組)、`o` (Others/其他人)。
- **專業用法（數字法）：** `r=4`, `w=2`, `x=1`。加總起來：`7` 代表全開 (`rwx`)，`6` 代表讀寫 (`rw-`)，`5` 代表讀與執行 (`r-x`)。
- 數字： **`r` (讀取) = 4**、 **`w` (寫入) = 2**、**`x` (執行) = 1**
- `-R` ： 連同資料夾內的所有子檔案一併遞迴修改
```
# 將網頁腳本設定為：擁有者全開、群組與其他人只能讀與執行 (常用於 Web Server)
chmod 755 script.sh

# 資安高強度設定：只有自己能讀寫，其他人完全看不到 (常用於 SSH 金鑰)
chmod 600 id_rsa
```

#### `chown` (Change Owner) — 變更檔案/目錄的「所有者」

- `chown <user>:<group> <filename>`：同時修改擁有者與所屬群組（用冒號隔開）
- `chown <user>  <filename>`：修改擁有者
- `-R` ： 連同資料夾內的所有子檔案一併遞迴修改

#### `chgrp` (Change Group) — 專門變更檔案的「所屬群組」
- `chgrp <group> <filename>`：修改群組

#### `chsh` (Change Shell) — 變更使用者的「預設終端環境」
- `chsh -s <path of shell> <user>`：`<user>`為空是自己，不用sudo

#### `chage` (Change Age) — 變更密碼的「有效期限與過期策略」
- `-l`：列出該使用者目前的密碼詳細生命週期（何時建立、何時過期）。
- `-M`：設定密碼的最長有效天數。
- `-E`：設定帳號的「絕對失效日期」（時間到了直接封鎖，很適合發放臨時實習生帳號）。
- 範例
```Bash
# 查看 kyle 的密碼過期資訊
sudo chage -l kyle

# 強制 kyle 每 90 天一定要換密碼，且過期前 7 天開始跳警告
sudo chage -M 90 -W 7 kyle

# 強制該使用者在「下次登入時」必須立刻修改密碼（新帳號交付常用）
sudo chage -d 0 kyle
```

#### `chattr` (Change Attribute) — 變更檔案底層屬性
- `+i` (Immutable)：**極致防禦鎖**。一旦加上，任何人都**不能刪除、不能修改、不能重新命名**該檔案（連 root 都拿它沒辦法）。
- `+a` (Append Only)：**日誌防禦鎖**。檔案只能被「追加內容」（如 `echo "log" >> file`），但不能刪除或修改舊內容。非常適合用在重要的系統日誌檔，防止駭客入侵後擦除痕跡。
- 範例
```Bash
# 保護系統核心設定檔（如 /etc/passwd），連 root 都不能亂動
sudo chattr +i /etc/passwd

# 解除這道防禦鎖（必須先解除才能修改或刪除）
sudo chattr -i /etc/passwd

# 查看檔案有沒有被下這種特殊屬性（不能用普通的 ls -l，要用 lsattr）
lsattr /etc/passwd
```
